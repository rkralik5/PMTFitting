The waveconvert program uses the CAEN xml readout file to create a root file for faster processing.

The program requires ROOT and BOOST

To compile the program make sure you have the ROOTSYS and BOOST environment variables set. The ROOTSYS variable is usually set by sourcing the {\ttfamily thisroot.\+sh} file from your ROOT installation The BOOST environment variable should be set to the directory containing the {\ttfamily boost} directory.

Then source {\ttfamily compile.\+sh} and the program should compile.

To use the program you should type in the following\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{waveconvert\ inputfile.xml\ outputfile.root}

\end{DoxyCode}


This will create two trees with the following structure

device frequency -\/ frequency of sampling the wave NSamples -\/ total number of waves resolution -\/ digitiser ADC resolution volt\+Low -\/ minimum voltage i.\+e. value from a reading of 0 volt\+High -\/ maximum voltage i.\+e. value from a readion of {\ttfamily resolution} data wavex -\/ vector of x axis values for each wave representing time in ns wavey -\/ vector of y axis values for each wave representing recorded voltage in mV clocktime -\/ time of recording of the waveform in units of Unix time in seconds
