\Hypertarget{md_scripts_2README_autotoc_md3}%
 Inputs are ROOT files created by scripts in the \href{../convert}{\texttt{ convert}} folder

All the scripts are based off of ROOT and require a ROOT version installed

For convenience some of the scripts can be run using a bash script. For example\+: ./\+Run\+Fit\+Single.sh input\+File.\+root -\/ will run the Fit.\+C script on a single file. ./\+Run\+Fit.sh /path/to/files -\/ will look through every file in a directory and run the Fit.\+C script on the root files it finds.

Originally created by \href{https://github.com/mahditaani}{\texttt{ @mahditaani}} and updated by \href{https://github.com/rkralik5}{\texttt{ @rkralik5}}\hypertarget{md_scripts_2README_autotoc_md4}{}\doxysection{\texorpdfstring{$<$a href="{}\+Draw\+Waveform.\+C"{} $>$\+Draw\+Waveform$<$/a$>$}{<a href="DrawWaveform.C" >DrawWaveform</a>}}\label{md_scripts_2README_autotoc_md4}
Draw a random selection of N waveforms from an input ROOT file using TGraph, save them into an output ROOT file

Run as\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{root\ 'DrawWaveform.C("{}inFileName"{},"{}outFileName"{},N)'}

\end{DoxyCode}
\hypertarget{md_scripts_2README_autotoc_md5}{}\doxysection{\texorpdfstring{$<$a href="{}\+Fit.\+C"{} $>$\+Fit$<$/a$>$}{<a href="Fit.C" >Fit</a>}}\label{md_scripts_2README_autotoc_md5}
This script reads in the waveforms, finds a minimum peak and then integrates around that peak. The results are plotted on a histogram and then a fit is run to characterise the PMT.

The result of the fit is written to a text file {\ttfamily pmt.\+txt}\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{filename\ q0\ s0\ q1\ s1\ mu\ gain\ photoelectronResolution\ peakToValleyRatio}

\end{DoxyCode}
\hypertarget{md_scripts_2README_autotoc_md6}{}\doxysection{\texorpdfstring{$<$a href="{}\+Dark\+Rate.\+C"{} $>$\+Dark\+Rate$<$/a$>$}{<a href="DarkRate.C" >DarkRate</a>}}\label{md_scripts_2README_autotoc_md6}
This script reads in the waveforms and then looks looks for the number of times the charge is higher than a threshold value in a sliding time window. The threshold is given by the single pe integrated voltage (q1) multiplied by some factor. The takes several measurements then calculates a mean and standard deviation. e.\+g. 
\begin{DoxyCode}{0}
\DoxyCodeLine{DarkRate.C("{}test.root"{},5,0.3)}

\end{DoxyCode}



\begin{DoxyItemize}
\item This means that the single pe has a mean integrated voltage of 5mV and it will seat a threshold of 0.\+3pe
\end{DoxyItemize}

The result of the fit is written to a text file {\ttfamily darkrates.\+txt}\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{filename\ meanDR\ stdDevDR}

\end{DoxyCode}
